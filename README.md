# Zero — AI integration

Landing page for Zero (AI integration), built with React + Vite + TypeScript +
Tailwind CSS + shadcn/ui. A single scrolling page with a fullscreen looping
video hero, glassmorphic surfaces, and cinematic display typography
(Instrument Serif + Inter).

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
